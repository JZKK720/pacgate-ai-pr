Agent Loop

Max-10-round iterative tool dispatch with citation extraction.

Agent 循环

最多 10 轮迭代工具调度，含引文提取。

1Build context: system prompt + persona + matter history + RAG results构建上下文：系统提示 + 角色 + 事项历史 + RAG 结果
2Call LLM via 3-tier router (Main → Mid → Low fallback)通过三层路由器调用 LLM（Main → Mid → Low 降级）
3Parse response: extract text + tool_calls + citations解析响应：提取文本 + tool_calls + 引文
4Dispatch tools: execute up to 10 tools per round, collect results调度工具：每轮最多执行 10 个工具，收集结果
5Append results to history, loop back to step 1 (max 10 rounds)将结果追加至历史，循环回步骤 1（最多 10 轮）
6Final response: extract citations via regex, format for SSE streaming最终响应：通过正则提取引文，格式化为 SSE 流式推送
