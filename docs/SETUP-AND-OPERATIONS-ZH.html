现场安装与运维操作手册（客户交付版）

用于 3 天现场部署窗口，聚焦可执行动作、验收结果与责任边界

本页是客户与项目管理方的执行总览。完整命令与低层细节仍以 deploy/SETUP-AND-OPERATIONS-ZH.md 为准。

1. 交付范围与运行边界

组件 运行方式 归属
pacgate-api / deer-flow / Postgres / nginx Docker Compose 客户本地环境
qm 协作空间 qm up 独立容器 客户本地环境
Ollama Windows 本机运行 客户本地环境

2. 三天部署节奏

1第 1 天 - 基础栈启动

  • 完成 AIPC 驱动、Docker、Ollama、Node.js 准备
  • 部署 client bundle，填写 .env，执行 install.ps1
  • 初始化默认租户与管理员账号

2第 2 天 - 协作联调

  • 部署 qm-pacgate 并创建 bridge 账号
  • 执行 setup-qm.ps1 与 qm up
  • 联调 deer-flow、qm、Agent OS 表层

3第 3 天 - 培训与验收

  • 管理员运维培训（启动、更新、日志、备份）
  • 律师使用培训（研究模式与协作模式）
  • 交接清单签收并关闭安装窗口

3. 客户侧验收口径

验收项 通过标准 状态
基础服务健康 docker compose ps 全部 healthy，/api/health 正常返回 必过
协作工作空间 qm Web UI 可登录，workflow 调用成功 必过
研究工作空间 /research/ 可用，模型调用与结果保存成功 必过
