# 律师日常通用 Prompts 指南

> **定位**：覆盖律师日常高频使用的基础工作场景——合同起草与审阅、劳动法、律师执业管理、争议预防与谈判、知识产权、税务、公司日常治理、房地产、法律培训与知识管理。
> **数字时效提示**：模板中出现的申报门槛、期限、比例、条文号等具体数字均以撰写时点为准、仅作示意，实际使用时一律以检索到的现行有效规定为准。
> **通用约定**（适用于本指南全部 prompts）：
> ① 复杂任务分步执行——先检索/分析，与律师确认关键假设后再成文，不要一次性输出全部交付物；
> ② 模板要求提供的合同、判决书、尽调材料等未提供时，先输出所需材料清单再继续，不得虚构事实作答；
> ③ 所有法规与案例引用须标注名称、文号/条文号、效力状态与检索来源，检索不到的明确说明，严禁编造；
> ④ 输出一律结论先行（先给一段结论摘要，再展开分析）。
>

## 一、合同起草与日常审阅

> **为什么重要？** 这是所有律师**频率最高**的日常工作——日常商业合同的起草、审阅、修改是律师每天花最多时间的事情。

### 1.1 日常商业合同审阅（通用）

```
请审阅以下合同，从【我方为买方/卖方/出租方/承租方/委托方/受托方】角度进行全面审查：

【粘贴或上传合同文本】

审阅维度及输出格式：

一、形式审查：
1. 合同名称是否与内容匹配
2. 当事人信息完整性（名称、地址、法定代表人、联系方式）
3. 签约日期与生效条件
4. 附件清单是否完整
5. 页码、条款编号是否连续

二、实质性条款逐条审阅：
对每个条款标注：
| 条款号 | 条款标题 | 风险等级 | 风险描述 | 修改建议 | 修改后文本 |

审阅维度：
1. 定义条款：关键术语定义是否清晰、完整、无歧义
2. 标的条款：标的描述是否明确、具体、可识别
3. 数量与质量：计量单位、质量标准、验收标准是否明确
4. 价格与支付：计价方式、支付节点、支付条件、发票要求
5. 交付与验收：交付时间/地点/方式、验收标准/期限/异议处理
6. 权利义务：双方权利义务是否对等、是否遗漏关键义务
7. 违约责任：
   - 违约情形是否穷尽
   - 违约金/赔偿计算方式是否明确
   - 是否有违约金过高/过低的风险
   - 违约与解除的关系
8. 合同解除：
   - 解除条件是否合理
   - 解除后的清算安排（恢复原状/赔偿损失）
   - 单方解除权是否过于宽泛或受限
9. 不可抗力：定义范围是否合理、通知义务、后果处理
10. 保密条款：保密信息范围、保密期限、例外情形、违约责任
11. 知识产权：IP归属、许可范围、侵权责任
12. 竞业限制/排他性条款（如适用）
13. 保证与陈述（如适用）
14. 争议解决：管辖法院/仲裁机构选择是否对我方有利
15. 适用法律（涉外合同）
16. 合同期限与续签
17. 通知条款：通知方式、送达地址、生效时间
18. 合同修改与转让
19. 可分割性条款
20. 完整协议条款

三、我方特殊关注点（根据我方身份）：
- 如为买方：验收标准是否合理、付款是否与验收挂钩、质量保证期
- 如为卖方：付款条件是否保障、是否过分限制退换货、知识产权保护
- 如为出租方：租金保障、违约解除权、租赁物损坏责任
- 如为承租方：租赁物适租性保证、维修责任、提前退租条件

四、整体风险评估：
- 🔴高风险条款（必须修改）
- 🟡中风险条款（建议修改）
- 🟢低风险条款（可接受但建议优化）

五、修改后完整合同文本（标注所有修改处）
```

### 1.2 合同关键条款谈判备忘录

```
请针对以下合同中的关键争议条款，起草一份谈判备忘录，帮助我方在谈判中争取有利条件：

合同类型：【如：SaaS服务合同/商业租赁合同/经销代理合同/技术许可合同】
我方身份：【如：采购方/供应商】
对方立场：【如：对方坚持XX条款不修改】

【粘贴争议条款】

谈判备忘录结构：

1. 条款争议点分析：
   对每个争议条款：
   a. 我方立场与理由：
      - 我方要求的条款内容
      - 法律依据和市场惯例支持
      - 不接受对方版本的风险分析
   
   b. 对方立场与理由：
      - 对方要求的条款内容
      - 对方可能的理由
   
   c. 市场惯例参考：
      - 同类合同中该条款的市场中间立场
      - 行业惯例做法
   
   d. 谈判策略：
      - 第一方案：我方理想版本
      - 第二方案：妥协中间版本
      - 第三方案：底线可接受版本
      - 每个方案的措辞文本

2. 谈判筹码分析：
   - 我方有哪些谈判优势（如：采购量大/独家供应商/时间压力）
   - 对方有哪些谈判优势
   - 可以用来交换的条款（在A条款让步换取B条款对我方有利）

3. 谈判顺序建议：
   - 哪些条款应优先谈判（高价值/高争议）
   - 哪些条款可以后谈或打包谈判
   - 谈判节奏建议

4. 话术建议：
   - 每个争议条款的谈判话术（专业但不强硬）
   - 应对对方反驳的话术
```

### 1.3 合同风险红黑榜（批量审阅）

```
请帮我批量审阅以下【5/10/20】份合同，生成一份合同风险红黑榜汇总：

【逐份上传或粘贴合同文本，每份标注合同名称和类型】

审阅要求：
1. 对每份合同进行快速扫描（不需要逐字逐句，重点看关键条款）
2. 为每份合同标注：
   | 合同名称 | 合同类型 | 风险等级（🔴高/🟡中/🟢低） | 关键风险点（最多3条） | 建议处理优先级 | 需修改条款摘要 |

3. 生成红黑榜排名：
   🔴 红榜（高风险，必须优先处理）：
   - 【合同名称】：【关键风险】
   
   🟡 黄榜（中风险，建议处理）：
   - 【合同名称】：【关键风险】
   
   🟢 绿榜（低风险，基本可签）：
   - 【合同名称】：【需微调之处】

4. 通用风险提示：
   - 这批合同中普遍存在的风险模式
   - 建议制定的标准条款模板（避免重复问题）

5. 合同模板建议：
   - 哪类合同需要制定我方标准模板
   - 模板中应包含的关键保护条款清单

输出为汇总表格（docx文档），便于管理层决策。
```

### 1.4 合同起草（从零开始）

```
请起草一份【合同类型：如技术服务合同/特许经营合同/委托开发合同/战略合作协议】：

合同基本信息：
- 甲方：【名称、地址、法定代表人】
- 乙方：【名称、地址、法定代表人】

- 合同金额/计价方式：【如：固定总价XX万元/按工时计费/按里程碑付款】
- 合同期限：【如：1年/3年/项目制】
- 我方身份：【甲方/乙方】

起草要求：

1. 合同结构（按以下顺序编排）：
   - 鉴于条款（背景说明）
   - 定义与解释
   - 标的/服务范围
   - 甲方权利义务
   - 乙方权利义务
   - 价格与支付
   - 交付/验收
   - 知识产权
   - 保密
   - 违约责任
   - 合同解除
   - 不可抗力
   - 争议解决

   - 一般条款（可分割性/完整协议/不可弃权/转让限制等）

2. 起草立场：
   - 从【我方】立场起草，确保权利义务对等但对我方适当有利
   - 关键条款提供"我方版"和"均衡版"两个选项
   - 每个条款标注起草思路说明（注释形式，不在正式文本中）

3. 特别注意：

### 1.5 合同快速扫描（10分钟版）

```
请对以下合同做快速风险扫描（非逐条审阅），10分钟内给出可签/需谈判/不可签的结论：

【粘贴或上传合同文本】
我方身份：【买方/卖方/服务方/委托方等】

只审查以下8类高风险点：
1. 主体与签署：对方主体适格性、签署人权限、是否需要盖章/骑缝章
2. 价款与支付：金额、支付节点是否与我方义务匹配、发票与税负
3. 违约责任：违约金水平、赔偿是否设上限、是否单向加重我方
4. 解除权：对方单方解除是否过宽、我方退出是否受限
5. 担保与连带：是否让我方承担保证/连带/兜底责任
6. 知识产权与保密：成果归属、保密义务是否对等
7. 争议解决：管辖/仲裁约定对我方是否不利
8. 生效与期限：生效条件、自动续约陷阱

输出（严格一页以内）：
- 总体风险评级：🔴不可签 / 🟡需谈判修改 / 🟢基本可签
- Top 5 问题（每条一句话：问题+改法）
- 一句话结论建议

不要输出逐条分析，不要复述合同内容。
```

## 二、劳动与雇佣法

> **为什么重要？** 劳动法问题几乎是所有企业客户的日常需求——招聘、入职、在职管理、离职、裁员，每个环节都有法律风险。很多律师即使不做专项劳动法业务，也需要处理客户日常的劳动法咨询。

### 2.1 劳动合同起草与审阅

```
请起草/审阅一份劳动合同：

员工信息：
- 员工姓名：【XX】
- 岗位：【如：高级工程师/销售总监/CEO】
- 工作地点：【XX城市】
- 合同期限：【固定期限3年/无固定期限/以完成一定任务为期限】
- 薪酬：【月薪XX元 + 年度绩效奖金】
- 是否为高管/核心员工：【是/否】

起草/审阅要点：

1. 必备条款合规性审查（《劳动合同法》第17条）：
   - 合同期限
   - 工作内容和工作地点
   - 工作时间和休息休假
   - 劳动报酬
   - 社会保险
   - 劳动保护、劳动条件和职业危害防护

2. 特别条款（针对【高管/核心员工】）：
   - 竞业限制条款：
     * 竞业限制范围（行业/地域/具体竞争对手名单）
     * 竞业限制期限（最长2年）
     * 竞业限制补偿金标准（不低于离职前12个月平均工资的30%）
     * 违约金条款
   - 保密条款
   - 知识产权归属条款
   - 服务期条款（如提供了专项培训费用）
   - 股权/期权条款衔接

3. 风险条款审查：
   - 试用期条款：
     * 试用期长度是否合规（3个月以上不满1年→不超过1个月；1年以上不满3年→不超过2个月；3年以上及无固定期限→不超过6个月；不满3个月或以完成一定任务为期限→不得约定试用期）
     * 试用期工资不低于正式工资80%
   - 调岗调薪条款：
     * 是否有合理调整机制
     * 单方调整的条件和限制
   - 解除条件：
     * 用人单位解除条件是否合法
     * 员工解除条件是否便利

4. 配套文件清单：
   - 保密协议
   - 竞业限制协议（建议单独签署）
   - 知识产权归属确认书
   - 岗位说明书
   - 员工手册/规章制度确认签收单

输出为Word文档，附配套文件模板。
引用《劳动合同法》《劳动合同法实施条例》及最新司法解释。
```

### 2.2 员工离职与裁员方案

```
请为以下企业制定员工离职/裁员法律方案：

企业信息：
- 企业名称：【XX】
- 裁员原因：【业务调整/并购后整合/经济性裁员/违法解除的补救】
- 涉及员工数量：【XX人】
- 员工类型：【普通员工/高管/孕期产期哺乳期员工/工伤员工/接近退休员工/外籍员工】
- 企业规模：【XX人（判断是否适用经济性裁员程序）】

方案框架：

1. 裁员合法性审查：
   - 是否符合《劳动合同法》第41条经济性裁员条件（企业转产/经营调整/客观经济情况重大变化）
   - 是否需要向工会/全体职工说明情况并听取意见
   - 是否需要向劳动行政部门报告
   - 优先留用人员审查（劳动合同较长/家庭无其他就业收入/有需要扶养的老人或未成年人）

2. 不得裁减人员审查：
   - 孕期/产期/哺乳期女职工（《劳动合同法》第42条）
   - 患病或非因工负伤在规定医疗期内的
   - 在本单位连续工作满15年且距法定退休年龄不足5年的
   - 正在担任集体协商代表的
   - 尚未完成工伤认定的

3. 离职方式选择矩阵：
   | 离职方式 | 适用条件 | 法律风险 | 成本 | 员工接受度 | 推荐指数 |
   | 协商解除 | 双方同意 | 低 | 协商补偿（通常N+1或更高） | 中-高 | ★★★★★ |
   | 经济性裁员 | 符合第41条 | 中 | N补偿 | 低 | ★★★ |
   | 客观情况重大变化（第40条第3项） | 须先协商变更 | 中-高 | N+1补偿 | 低 | ★★ |
   | 单方解除（第39条过错解除） | 需有充分证据 | 高 | 无补偿 | 极低 | ★ |

4. 补偿方案设计：
   - 经济补偿金计算（N或N+1）
   - N的确定：每满1年支付1个月工资，6个月以上不满1年按1年算，不满6个月支付半个月工资
   - 月工资标准：离职前12个月的平均工资（含奖金、津贴等）
   - 高工资员工的补偿上限（当地上年度职工月平均工资3倍，最长12年）
   - 代通知金（+1）的适用条件
   - 额外协商补偿的建议范围
   - 社保/公积金转移安排
   - 年度奖金/未休假期的处理

5. 离职流程时间线：
   - 内部决策 → 工会/职工说明 → 劳动部门报告（如适用） → 通知员工 → 协商 → 签署协议 → 办理离职 → 补偿支付
   - 每步的法律要求和时间节点

6. 风险防控：
   - 劳动仲裁/诉讼的风险评估
   - 群体性事件的预防措施
   - 离职协议的关键条款（一次性解决/无后续争议/保密/竞业衔接）
   - 证据保留要求

7. 涉外员工特殊处理（如适用）：
   - 外籍员工的就业证注销
   - 外籍员工的出境安排

输出为裁员法律方案（Word文档），含离职协议模板和补偿计算表。
```

### 2.3 劳动争议应对

```
请基于以下劳动争议情况，制定应对方案：

争议信息：
- 争议类型：【违法解除赔偿金/拖欠工资/工伤待遇/竞业限制违约/未签劳动合同双倍工资/社保补缴/加班费等】
- 员工信息：【姓名、岗位、入职时间、离职时间、月薪】
- 我方身份：【用人单位/员工】
- 员工诉求：【简述】
- 已有程序：【是否已申请劳动仲裁/已收到仲裁通知】

应对方案框架：

1. 争议焦点分析：
   - 员工主张的法律依据和构成要件

   - 专利：是否有效/保护范围/是否即将到期
   - 商标：是否有效/注册类别/是否驰名商标
   - 著作权：是否受保护/保护期限/独创性程度

2. 侵权比对分析：
   - 专利侵权：全面覆盖原则/等同原则
   - 商标侵权：混淆可能性分析（音形义/商品类似性/知名度）
   - 著作权侵权：接触+实质性相似分析
   - 商业秘密侵权：秘密性+价值性+保密措施+同一性比对

3. 抗辩分析：
   - 专利：现有技术抗辩/先用权抗辩/权利用尽/临时过境/科研实验例外/Bolar例外
   - 商标：在先使用/描述性使用/指示性使用/合理使用/不混淆抗辩
   - 著作权：合理使用/独立创作/思想表达二分法
   - 商业秘密：独立研发/反向工程/合法获取

4. 不侵权声明/确认之诉评估（如我方为被指控方）

5. 损失/赔偿评估：
   - 权利人实际损失
   - 侵权人违法所得
   - 法定赔偿范围
   - 惩罚性赔偿适用条件（《专利法》第71条故意侵权）

6. 诉讼/非诉讼策略建议：
   - 是否发函/回应函
   - 是否申请宣告权利无效（专利无效宣告/商标撤销）
   - 和解谈判策略
   - 诉讼风险评估

请使用华宇元典数据库检索同类IP侵权案例。
输出IP侵权分析报告。
```

## 六、税务法律

> **为什么重要？** 几乎所有交易结构设计都涉及税务考量，税务法是律师做交易结构设计时的底层逻辑。

### 6.1 交易税务结构优化分析

```
请为以下交易进行税务结构优化分析：

交易信息：
- 交易类型：【如：股权转让/资产转让/企业重组/跨境收购/知识产权转让】
- 交易方：【卖方XX/买方XX】
- 交易金额：【约XX万元/美元】
- 现有交易结构：【简述】
- 优化目标：【如：降低整体税负/递延纳税/避免双重征税】

税务分析框架：

1. 现有结构的税负分析：
   - 所得税（企业所得税/个人所得税）
   - 增值税/营业税
   - 印花税
   - 预提税（如涉及跨境）
   - 土地增值税/契税（如涉及不动产）
   - 总税负率估算

2. 替代结构的税负比较：
   结构A：【现有结构】总税负约XX%

     * 具有合理商业目的
     * 股权/资产比例≥50%
     * 12个月内不改变实质性经营活动

4. 跨境税务问题（如适用）：
   - 税收协定适用（避免双重征税）
   - 预提税税率（协定优惠税率vs.法定税率）
   - 常设机构风险
   - 受控外国公司规则（CFC）
   - 转移定价合规

5. 合规风险预警：
   - 反避税风险（一般反避税条款/特别纳税调整）
   - 虚假交易的税务风险
   - 税务机关质疑的商业目的

6. 推荐方案及实施步骤

注意：税务分析仅供参考，具体税务筹划应由税务师/会计师配合完成。
输出税务结构分析报告。
