# 非诉律师实用 Prompts 指南

> **适用对象**：投融资、跨境并购、境内并购、跨境争议解决、Web3与区块链（交易/架构类）、公司法日常业务、资本市场与IPO、股权激励、银行与金融交易、海商与航运、PPP与能源基础设施领域资深非诉律师
>
> **使用说明**：以下 prompts 为可直接复制使用的指令模板，`【】`内为需替换的变量。结合 AI系统的联网搜索、华宇元典法律数据库、docx/PDF文档生成、多语言翻译等能力，可显著提升法律工作效率。
> **数字时效提示**：模板中出现的申报门槛、期限、比例、条文号等具体数字均以撰写时点为准、仅作示意，实际使用时一律以检索到的现行有效规定为准。
> **通用约定**（适用于本指南全部 prompts）：
> ① 复杂任务分步执行——先检索/分析，与律师确认关键假设后再成文，不要一次性输出全部交付物；
> ② 模板要求提供的合同、判决书、尽调材料等未提供时，先输出所需材料清单再继续，不得虚构事实作答；
> ③ 所有法规与案例引用须标注名称、文号/条文号、效力状态与检索来源，检索不到的明确说明，严禁编造；
> ④ 输出一律结论先行（先给一段结论摘要，再展开分析）。
>

## 一、投融资（Investment & Financing）

### 1.1 Term Sheet 起草

```
请帮我起草一份【A轮/B轮/C轮】融资的Term Sheet，具体条件如下：
- 投资方：【美元基金/人民币基金】
- 融资金额：【2000万美元】
- 投前估值：【1亿美元】
- 优先股类型：【Series A Preferred Stock】
- 投资人董事席位：【1席】

请包含以下标准条款，并标注每条的市场惯例范围和谈判弹性空间：
1. 估值与对赌调整（VAM）机制
2. 优先清算权（1x non-participating / participating）
3. 反稀释保护（full ratchet / broad-based weighted average）
4. 优先购买权与共售权
5. 回购权（触发条件、回购价格计算方式）
6. 信息权与检查权
7. 创始人锁定与服务期要求
8. 一票否决权（保护性条款）清单
9. 优先认购权
10. 陈述与保证及赔偿上限

输出格式：中英双语对照，每条注明"投资人友好版"/"创始人友好版"/"市场中间版"三种版本的关键差异。
```

### 1.2 投融资尽职调查清单

```
请生成一份针对【SaaS/AI医疗/新能源/消费科技】领域初创企业的投融资法律尽职调查清单，要求：

1. 按以下模块组织，每个模块列出具体核查事项和所需文件：
   - 公司设立与治理（营业执照、章程、股东名册、董事会决议）
   - 股权结构（代持、期权池、历史融资轮次、ESOP）
   - 知识产权（专利、商标、软著、域名、开源合规）
   - 劳动用工（劳动合同、社保公积金、竞业限制、核心员工清单）
   - 重大合同（前五大客户合同、供应商协议、租赁合同）
   - 数据合规（数据收集合法性、隐私政策、数据出境）
   - 税务（税务登记、欠税、税收优惠、转移定价）
   - 诉讼仲裁与行政处罚
   - 环保与行业资质（如适用）

2. 每个核查事项标注风险等级（高/中/低）
3. 列出DD过程中常见的"红旗"（Red Flags）信号
4. 提供英文版清单（供美元基金投资人使用）

输出为docx文档，便于团队协作勾选。
```

### 1.3 投资协议条款审阅

```
请审阅以下《增资协议》/《Share Purchase Agreement》核心条款，重点分析：

【粘贴协议文本或上传文件】

审阅维度：
1. 估值调整机制（对赌）：
   - 触发条件是否合理（业绩/上市/IPO时间表）
   - 补偿方式（股权补偿/现金补偿/股权回购）的计算公式是否公平
   - 是否存在"叠加触发"风险

2. 回购权：
   - 回购触发事件清单是否过宽
   - 回购价格计算方式（本金+利息 vs. 公允价值）
   - 回购权行使期限

3. 优先清算权：
   - 倍数是否符合市场惯例
   - 参与型 vs. 非参与型的选择
   - "清算事件"定义范围

4. 反稀释条款：
   - full ratchet vs. weighted average 的选择依据
   - 例外情形清单（豁免情形）

5. 保护性条款（一票否决权）：
   - 否决事项清单是否合理
   - 是否存在创始人经营自主权被过度限制的风险

输出格式：
- 逐条标注【投资人立场】【创始人立场】【市场惯例】三个视角的评析
- 标注需谈判修改的条款（🔴必须修改 / 🟡建议修改 / 🟢可接受）
- 给出修改建议文本（track changes 式标注）
```

## 二、跨境并购（Cross-border M&A）

> **与第三节境内并购的关系**：跨境并购侧重境外目标、多法域审批、外汇与税务优化；境内并购侧重中国特有的国资/外资/反垄断/经营者集中审批、上市公司并购规则等。两节互补，形成并购业务的完整覆盖。

### 2.1 交易结构设计

```
我们正在为【中国上市公司/中国PE基金】收购【德国/美国/日本】某【工业自动化/半导体/医疗器械】企业设计交易结构，目标估值约【5亿欧元】。

请从以下维度分析"直接收购 vs. 通过【卢森堡/荷兰/新加坡】SPV收购"两种方案的利弊：

1. 税务效率：
   - 股息预提税税率对比（各法域税收协定网络）
   - 资本利得税/退出税
   - 印花税/转让税
   - 利息扣除与资本弱化规则

2. 监管审批：
   - 目标国FDI/国家安全审查要求
   - 反垄断申报阈值与时间线
   - 中国境外投资审批（ODI备案/核准）

3. 外汇管制：
   - 资金出境路径与时间
   - 利润汇回路径

4. 员工保留：
   - 目标国劳动法对并购的限制
   - 工会/员工代表咨询或同意要求

5. 风险隔离：
   - SPV的有限责任保护范围
   - 或有负债的隔离效果

请输出对比矩阵表，并给出推荐方案及理由。
```

### 2.2 SPA 核心条款审阅

```
请审阅以下Share Purchase Agreement中的核心条款，关注跨境交易特有风险：

【粘贴SPA文本或上传文件】

重点审阅条款：
1. 陈述与保证（Reps & Warranties）：
   - MAC/MAE条款的范围与排除项
   - 合规陈述是否覆盖反腐败（FCPA/UKBA）、制裁、数据保护
   - 知识产权陈述（权属、不侵权、开源合规）
   - 数据保护陈述是否满足GDPR/PIPL要求
   - 陈述的"knowledge qualifier"限定范围

2. 交割后赔偿机制（Indemnification）：
   - 一般赔偿 vs. 特定赔偿（Specific Indemnities）
   - 赔偿上限（Cap）、起赔额（Basket/Deductible）
   - 时效安排（一般索赔 vs. 基本陈述/税务陈述）
   - 预扣款/托管安排（Escrow / R&W Insurance）

3. 交割条件（CPs）：
   - 监管审批作为CP的处理（hell or high water clause?）
   - MAC条款作为CP的合理性
   - 无重大不利变化的认定标准

4. 价格调整机制：
   - 交割日账目调整 vs. 锁箱机制（Locked Box）
   - 运营资本调整的计算方法
   - 争议解决机制（独立会计师裁决）

5. 限制性承诺（Restrictive Covenants）：
   - 卖方竞业禁止的范围、地域、期限
   - 不招揽客户/员工条款

输出格式：逐条标注风险点（🔴/🟡/🟢），给出买方/卖方视角分析，并提供修改建议条款文本。
```

### 2.5 交割后整合法律风险评估

```
请对本次跨境并购的投后整合（Post-merger Integration）阶段进行法律风险评估：

收购方：【中国企业】，目标公司：【德国/日本企业】，行业：【制造业/科技】

评估维度：
1. 劳动法整合风险：
   - 目标国裁员/调岗/降薪的法律限制
   - 工会/员工代表的信息与咨询权（如德国Co-determination）
   - 留用奖金（Retention Bonus）的税务处理
   - 养老金负债转移问题

2. 知识产权整合：
   - IP权属变更与许可协议承继
   - 联合开发IP的权属安排
   - 开源代码合规风险传导

3. 数据跨境传输合规：
   - 收购后数据整合涉及的跨境数据传输
   - 目标国数据保护法限制（GDPR第6章合法性基础）
   - 数据本地化要求

4. 关联交易与转移定价：
   - 采购/销售集中化的转移定价风险
   - 关联交易披露义务
   - 事先裁定（APA）申请的必要性

5. 反商业贿赂合规整合：
   - FCPA/UKBA对收购方的继承责任（successor liability）
   - 目标公司历史合规问题尽职调查（pre-acquisition compliance review）

6. 税务整合：
   - 税务居民身份变更
```

```
1. 减资类型判断：

   - 简化公告程序（仅需在国家企业信用信息公示系统公告）

   - 公告期满无异议→向登记机关申请注销

3. 简易注销的风险：
   - 承诺不实的后果：股东对公司债务承担连带责任，不受出资比例限制
```

### 高效使用技巧

1. **分步指令**：复杂任务拆分为多步，如"先检索法规→再分析适用→最后出备忘录"
2. **上下文累积**：同一案件的多轮对话中，AI系统 会保持上下文，无需重复背景
3. **文件联动**：上传尽调文件 → 分析 → 生成报告 → 存入docx文档，一条龙完成
4. **模板复用**：将常用 prompt 保存为模板，替换变量即可快速调用
5. **多法域并行**：一次提问中列出多个法域，AI系统 可并行分析对比
6. **法规时效提醒**：设置自动化任务，定期检索特定领域的法规更新
