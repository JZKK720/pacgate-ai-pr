中国法律尽职调查报告系统 · 改造方案
配套：《dd-agents 中国法智能体改写清单.md》《Awesome-Legaltech-资源清单.md》
附录 A/B 目标：把开源/官方法律 AI 框架改造成能产出可交付的中国法律尽职调查报
告的系统。 本文给出两套方案供对照：方案 A = 以 corporate-legal 为骨架；方案 B
= dd-agents + corporate-legal 组合（理想版）。 整理日期：2026-06-23 ｜ 版本：v1.0
0. 两个基础组件回顾
- corporate-legal（anthropics/claude-for-legal 子插件）：法律单域的公司/并购法务工作流。
技能产出**按本所自有格式（house format）**的尽调件：问题提取、带引用表格审查、重大
合同披露表、交割清单、分层摘要；内置 practice profile（边用边学模板）、引用分级、特权
标注、律师复核 gating。绑 Claude 运行时。
- dd-agents：9 域取证式交叉尽调引擎。Python、模型无关（DeepSeek/本地开箱）、读整个
数据室、OCR、并行抽取 + 跨域交叉引用 + 溯源 + 质量门，输出 findings（
HTML/Excel/JSON）。停在"发现"，不出律所格式报告。
一句话分工：dd-agents 擅长"读海量数据室 + 跨域找问题 + 溯源"；corporate-legal 擅长"按本所模
板把发现写成可交付报告 + 合规护栏"。
方案 A：以 corporate-legal 为骨架改造
适用：中小体量、法律单域尽调，追求快速出报告。最省事、最接近交付物。

A.2 中国法律尽调报告章节体系（issue-extraction 的 category）
1.  主体资格与历史沿革（设立、历次股权变更、出资瑕疵、增减资）
2.  公司治理（章程、三会决议、印章、对外担保程序）
3.  股权结构（代持、质押/冻结、对赌与回购、VIE/外资准入）
4.  主要资产（土地房产权属、知识产权、设备、特许资质）
5.  重大合同（控制权变更/转让限制条款、关联交易）
6.  债权债务与对外担保

7. 劳动人事与社保公积金（欠缴敞口、经济补偿、竞业）
8. 税务合规（股权转让税、土增/契税、特殊性重组、间接转让）
9. 环保与安全生产（排污许可、环评、土壤污染、安全生产）
10. 诉讼仲裁与行政处罚（含被执行/失信）
11. 业务资质与行政许可（可转让性、重新审批）
A.3 Practice Profile（CLAUDE.md）模板要点
- 本所法律尽调报告标准目录（章节顺序与命名）
- 风险定级口径：重大/重要/一般；或红/黄/绿
- 引用规范：法条+条款号、文件名+页码、案号
- 保留意见与免责声明模板
- 尽调清单基线（标准文件清单）
- 业务条线特别关注点（房地产/制造/金融/TMT 各一段）
A.4 连接器（.mcp.json）与数据
- 企查查 MCP/API：工商、股东、涉诉、被执行、行政处罚
- 裁判文书 / 法信：诉讼仲裁检索
- 北大法宝 / 元典：法规检索与时效核验（引文护栏）
- 数据室：Box/SharePoint/本所 DMS（国产可用对象存储/内部 DMS）
- OCR：TextIn / PaddleOCR（扫描件）
A.5 运行时与模型
默认 Claude；本地化用 DeepSeek 经 Anthropic 兼容网关，或按附录 A 把提示词移植到自有
Agent 框架。

模型无关、本地部署、OCR 分层摘要、合规护栏（引用/特权/复核 gating）

B.3 取舍与合并（避免重复）
- dd-agents 的 HTML Go/No-Go 报告 → 降级为内部分析视图，不作对外交付。
- corporate-legal 的 diligence-issue-extraction 直接读 VDR → 改为读 dd-agents 的
findings，避免两次抽取。

向量库、模板库——两层共用一套。

建议路线：先 A 见效，再演进到 B。方案 A 用最小代价产出可交付的中国法律尽调报告，验证本
所模板与护栏；待大体量、全口径需求出现，再把 dd-agents 接到前端做分析引擎，
corporate-legal 成文层不变、仅改输入源——平滑升级，不推倒重来。

共用前置条件（A、B 都需要）
1. 中国法智能体/提示词改写：见《dd-agents 中国法智能体改写清单》，A 用于改
corporate-legal 技能提示词，B 用于改 dd-agents persona。
2. 连接器接入：企查查、裁判文书/法信、北大法宝/元典（见《百宸AI系统资源接入清单.docx
》）。
3. 底座模型：DeepSeek 或本地中文法律模型（数据不出境），经兼容网关接入。
4. 报告模板与定级口径：本所法律尽调报告标准目录 + 风险分级 + 引用规范 + 免责声明，固
化进 practice profile / 模板库。
5. 律师复核环节：任何方案的输出都是待复核草稿，最终结论由执业律师出具。
本方案为系统改造的设计参考，不构成法律意见。
