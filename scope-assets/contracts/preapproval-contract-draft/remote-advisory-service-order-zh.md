## 2. 服务范围

乙方按本订单约定，向甲方提供以下远程顾问服务：

- 部署后工作流调优（prompt、playbook、workflow 调整）
- Connector 规划与 MCP 扩展指导
- 知识库增量导入的结构化指导
- Phase 2 技术评估与方案建议
- 系统级远程排障（非硬件故障）
- 双方书面确认的其他远程顾问工作

**明确不包含**：硬件故障维修（走 HWOS 合同保修条款）、现场支持（另签《现场服务订单》）、固定交付范围内的交接说明与初始工作流演示。
